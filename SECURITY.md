# PMan security policy

Report PartCAD product vulnerabilities using the upstream process in
`.github/SECURITY.md`. Report BackboneNeo fork governance issues privately to
the repository owner, `@NeoUKR`.

Do not commit credentials, customer data, private IVINS-P geometry, provenance
records, exports, or backups to this public fork. The private CAD package lives
in `BackboneNeo/PMan-IVINS-P`.

Publishing PartCAD Python packages, GitHub Releases, tags, container images, or
agent plugins from PMan is prohibited. The workflow guards are security
controls; changing them requires a High-risk Change Issue and explicit owner
approval.
